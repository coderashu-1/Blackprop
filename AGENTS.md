# BlackProp coding notes

- Use Next.js App Router and TypeScript.
- Prefer Server Components unless interactivity requires `"use client"`.
- Use Tailwind utility classes and keep global CSS for tokens/effects only.
- Preserve the premium dark visual system: black/graphite, gold, silver, white.
- Avoid copying third-party text, logos, imagery, reviews, or proprietary UI exactly.
- Keep sections responsive from 320px upward.
- Reuse components instead of duplicating markup.
- Before merging UI work, run `npm run lint` and `npm run build`.
